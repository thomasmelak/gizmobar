Gizmobar

A fast, native macOS status bar written in Swift. AeroSpace workspaces, rich now playing, 3D models and TypeScript plugins, without a single shell process on the render path.

Everything a bar does, done natively

Providers read macOS APIs in-process and push events onto one bus. SwiftUI redraws at most once per frame. Nothing polls a shell script.

Fast by design

No process starts on the render path. Every plugin render is timed against a 2 ms budget.

AeroSpace workspaces

One aerospace subscribe stream, app icons per workspace, click to switch. No callbacks in your config.

Rich now playing

Spotify, Music and any app through mediaremote-adapter. Album art colors, scrubbing, and a live spectrum from a Core Audio tap.

TypeScript plugins

Write widgets in TypeScript with typed providers. Each plugin gets its own sandboxed JavaScriptCore VM and permissions.

3D models and a globe

Put a glTF, GLB or USDZ model on the bar, play its clips and orbit it. A still model costs nothing. Plus a sun-lit dot globe.

Themes and icons

12 bundled themes, switchable from the bar. Icon packs per bundle ID, your own SVGs picked up live.

Auto-hide

Slides away over fullscreen apps and comes back when the pointer touches the edge, like the macOS menu bar.

A real CLI

gizmo trigger pushes your own events, gizmo reload applies config, gizmo debug shows render times.

A widget in a few lines

Run gizmo new my-plugin, add it to your layout, and save. The bar rebuilds it with esbuild on every save and keeps its storage across reloads.

Plugins ask for what they use: provider:cpu, net:api.example.com, exec. Nothing else is reachable.

import { definePlugin, ui } from "@gizmobar/sdk";

export default definePlugin({
  id: "status-pet",
  setup(ctx) {
    const cpu = ctx.use("cpu", { every: "2s" });
    const media = ctx.use("media");

    return () => ui.scene({
      model: "models/gizmo-bot.glb",
      look: "toon",
      animation: media.value?.playing ? "dance"
        : (cpu.value?.usage ?? 0) > 0.8 ? "run" : "idle",
      onClick: () => ctx.scene.play("wave", { once: true }),
      popover: { size: 240, orbit: true },
    });
  },
});

Install

macOS 14 or newer. Pick whichever way you like; every option installs the same app.

  1. Download Gizmobar.dmg from the latest release.

  2. Open the DMG and drag Gizmobar onto the Applications folder.

  3. Open Gizmobar from Applications. The first time, macOS will block it because the app isn't notarized; see Opening it the first time below.

  4. The first launch links gizmo into ~/.local/bin. Copy the example config into ~/.config/gizmobar (it never overwrites):

    $ ~/.local/bin/gizmo config init

  1. Add the tap and install the cask:

    $ brew tap thomasmelak/gizmobar https://github.com/thomasmelak/gizmobar
$ brew install --cask gizmobar

  2. Homebrew clears the quarantine flag, puts gizmo on your PATH and starts the bar, so there's no security prompt.

  3. Copy the example config, and update later with brew upgrade:

    $ gizmo config init
$ brew upgrade --cask --greedy gizmobar

  1. Paste this into Terminal:

    $ curl -fsSL https://raw.githubusercontent.com/thomasmelak/gizmobar/main/install.sh | bash

  2. The script downloads the latest release into /Applications, clears the quarantine flag, links gizmo into ~/.local/bin, copies the example config and starts the bar. Nothing is built on your Mac and you don't need Xcode.

  1. Only needed if you want to work on Gizmobar itself. You need the Xcode Command Line Tools with Swift 6 (xcode-select --install).

  2. Clone, build and install:

    $ git clone https://github.com/thomasmelak/gizmobar.git
$ cd gizmobar
$ make install   # Gizmobar.app into /Applications, gizmo into ~/.local/bin
$ make config    # copy the example config
$ open -a Gizmobar

Opening it the first time. Release builds are signed in CI but not notarized by Apple, so the first launch of a downloaded copy shows a "cannot be opened" or "Apple could not verify" message. Open System Settings › Privacy & Security, scroll to the message about Gizmobar and click Open Anyway, or remove the quarantine flag in Terminal:

$ xattr -dr com.apple.quarantine /Applications/Gizmobar.app

Homebrew and the one-line installer do this for you.
