Gizmobar

A fast, native macOS status bar written in Swift. AeroSpace workspaces, rich now playing, 3D models and TypeScript plugins, without a single shell process on the render path.

Everything a bar does, done natively

Providers read macOS APIs in-process and push events onto one bus. SwiftUI redraws at most once per frame. Nothing polls a shell script.

Fast by design

No process starts on the render path. Every plugin render is timed against a 2 ms budget.

AeroSpace workspaces

One aerospace subscribe stream, app icons per workspace, click to switch. No callbacks in your config.

Rich now playing

Spotify, Music and any app through mediaremote-adapter. Album art colors, scrubbing, and a live spectrum from a Core Audio tap.

TypeScript plugins

Write widgets in TypeScript with typed providers. Each plugin gets its own sandboxed JavaScriptCore VM and permissions.

3D models and a globe

Put a glTF, GLB or USDZ model on the bar, play its clips and orbit it. A still model costs nothing. Plus a sun-lit dot globe.

Themes and icons

12 bundled themes, switchable from the bar. Icon packs per bundle ID, your own SVGs picked up live.

Auto-hide

Slides away over fullscreen apps and comes back when the pointer touches the edge, like the macOS menu bar.

A real CLI

gizmo trigger pushes your own events, gizmo reload applies config, gizmo debug shows render times.

A widget in a few lines

Run gizmo new my-plugin, add it to your layout, and save. The bar rebuilds it with esbuild on every save and keeps its storage across reloads.

Plugins ask for what they use: provider:cpu, net:api.example.com, exec. Nothing else is reachable.

import { definePlugin, ui } from "@gizmobar/sdk";

export default definePlugin({
  id: "status-pet",
  setup(ctx) {
    const cpu = ctx.use("cpu", { every: "2s" });
    const media = ctx.use("media");

    return () => ui.scene({
      model: "models/gizmo-bot.glb",
      look: "toon",
      animation: media.value?.playing ? "dance"
        : (cpu.value?.usage ?? 0) > 0.8 ? "run" : "idle",
      onClick: () => ctx.scene.play("wave", { once: true }),
      popover: { size: 240, orbit: true },
    });
  },
});

Up and running in five commands

You need macOS 14 or newer and Swift 6. The Xcode Command Line Tools are enough.

# build, install to /Applications, link `gizmo` into ~/.local/bin
git clone https://github.com/thomasmelak/gizmobar && cd gizmobar
make install
# copy the example config into ~/.config/gizmobar, then start the bar
make config
open -a Gizmobar
